## Step 1 — Run Setup (One Click)

### Windows (easiest)
Double-click **`setup.bat`** in this folder.

### PowerShell (advanced options)
```powershell
# Standard setup
.\setup.ps1

# Force CUDA/GPU PyTorch install (NVIDIA GPU users)
.\setup.ps1 -GPU

# Skip final import verification (faster)
.\setup.ps1 -SkipTests

# Setup only, don't launch server
.\setup.ps1 -NoServer -NoBrowser
```

The setup script automatically handles:
- ✅ Python 3.11+ detection (auto-installs via winget if missing)
- ✅ FFmpeg download & setup (auto-downloads BtbN GPL build if missing)
- ✅ Virtual environment creation / self-healing repair
- ✅ All Python dependencies (`requirements.txt` + editable install)
- ✅ `.env` creation with secure random keys
- ✅ Storage directory structure
- ✅ Database initialization & admin user seeding
- ✅ Port 8000 conflict detection

## Troubleshooting

| Problem | Fix |
|---|---|
| `ffmpeg: command not found` | Re-run `setup.ps1` — it auto-downloads FFmpeg |
| `ModuleNotFoundError: shorts_engine` | Run: `.venv\Scripts\pip install -e .` |
| `Port 8000 in use` | Edit `DASHBOARD_PORT=8080` in `.env` or re-run setup (it offers to kill the process) |
| `sqlite3.OperationalError: database is locked` | Run: `python run.py reconcile-stale` |
| `pip install fails` | Check internet connection; setup retries 3× automatically |
| `.venv is corrupted` | Delete `.venv` folder and re-run `setup.ps1` — it rebuilds cleanly |
| Python not found | Install Python 3.11 from https://www.python.org/downloads/ (check "Add to PATH") |
